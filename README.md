# 🐾 PetNest – Pet Adoption Platform

## Project Name

**PetNest**

---

## Purpose

PetNest is a modern pet adoption platform built to connect pet owners and adopters in one place. Users can explore available pets, search by category or breed, view detailed information, and request pet adoption through a secure authentication system.

The goal of this project is to simplify the pet adoption process and create a clean, user-friendly experience.

## Features

### ✨ Key Features

* 🐶 Browse all available pets with responsive card layout
* 🔍 Search pets by name and breed
* 🔐 Secure authentication with protected routes
* 📄 View detailed pet information page
* ➕ Add new pets through dashboard
* ❤️ Adopt pets and track adoption requests
* 👤 Personalized dashboard with user profile
* 📱 Fully responsive UI for mobile and desktop
* ⚡ Fast rendering with Next.js App Router
* 🎨 Modern UI built using HeroUI + Tailwind CSS

## Installation

Clone repository

```bash
git clone <repo-url>
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```
